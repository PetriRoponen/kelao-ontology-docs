Finnish Social Security Core Ontology: Description back to ToC

The core version contains only the central social security concepts (benefits, eligibility, life situations, legislation, customership, services, areas). Extensions (e.g. data products) are deliberately kept outside the core ontology. Reuses external vocabularies and ontologies: PROV-O, ELI, CPSV, PTV (Finnish Service Catalogue), schema.org, WGS84 Geo, W3C Locn, W3C Org, SHACL, and Kela's terminological vocabulary (v7.1).
